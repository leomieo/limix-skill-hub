# drawio-skill — hướng dẫn tiếng Việt

Tạo, chỉnh sửa và kiểm định sơ đồ draw.io có thể tiếp tục sửa; hỗ trợ kiến trúc, UML, ERD, swimlane và chuyển đổi từ mã.

## Cách dùng

- Yêu cầu tác vụ và cung cấp đầu vào, đích đến cùng định dạng mong muốn.
- Ví dụ: “Dùng drawio-skill để tạo ERD có thể chỉnh sửa từ schema SQL này.”
- Làm theo quy trình, giới hạn và yêu cầu duyệt trong `SKILL.md` gốc. Chỉ đọc reference mà tác vụ cần.

## Lưu ý

Yêu cầu Python 3. draw.io cần cho xuất hình; Graphviz tùy chọn cho bố trí tự động. PyYAML hỗ trợ đầu vào YAML, python-pptx hỗ trợ xuất PPTX, Pillow hỗ trợ GIF. Chưa cài hoặc chạy các công cụ này.

Tệp hướng dẫn này chỉ hỗ trợ sử dụng; không thay đổi core tiếng Anh hoặc tự cấp quyền chạy script.

# answer-me-with-html — hướng dẫn tiếng Việt

Skill trả lời câu hỏi khó bằng một trang HTML đọc được thay vì cả khối chữ — model chỉ viết nháp Markdown (khoảng 1/8 số token so với tự viết HTML), CLI đi kèm dựng trang hoàn chỉnh theo component (sequence, flow, state, er, class, api, tree, timeline, chart, annot, kv, callout, ask), có 3 theme (blueprint/shadcn/paper) sáng/tối, tự sửa lỗi nháp, nhúng code thật từ file dự án, kèm video giải thích kiểu 3b1b và chế độ always-on cho mọi kết luận.

## Cách dùng

- Gọi kỹ năng bằng tên gốc `answer-me-with-html` hoặc mô tả yêu cầu bằng tiếng Việt.
- Ví dụ: “Dùng answer-me-with-html cho tác vụ của tôi; giải thích kết quả bằng tiếng Việt.”
- Cung cấp đầu vào và kết quả mong muốn. Các điều kiện, giới hạn và bước duyệt tuân theo `SKILL.md` gốc.

## Ngôn ngữ và giới hạn

Tài liệu này chỉ giải thích cho người dùng; không thay đổi quy trình thực thi. Agent đọc `SKILL.md` khi kích hoạt, chỉ đọc reference phù hợp khi cần. Không nạp đồng thời bản dịch đầy đủ. Giữ nguyên tên Tool, API, MCP, CLI, tham số, mã nguồn và đường dẫn.

Trạng thái: **quarantined**. Chưa chạy thử script hoặc dịch vụ ngoài. Việc quét tĩnh không bảo đảm an toàn; quyền sử dụng do Limix Bot và chủ bot quyết định.
